## [1.0.0] - 2026-08-08

### Added

- Per-user Windows Setup executable and portable self-contained ZIP.
- Reproducible release checksums and tag-driven GitHub release automation.
- In-app About window with version, project, and local-data access.
- Public repository contribution, security, issue, and pull-request guidance.

### Included

- Keyboard-first GitHub issue capture with global shortcut and system tray.
- Repository metadata, templates, quick tokens, attachments, drafts, and history.
- Light, dark, and system themes with configurable launch-at-login behavior.
